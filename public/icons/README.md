# PWA Icons

Place your PWA icons here with the following sizes:
- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png

You can generate these icons from a single source image using online tools like:
- https://realfavicongenerator.net/
- https://www.pwabuilder.com/imageGenerator

## Icon Requirements
- Format: PNG
- Background: Solid color or transparent
- Content: Should be recognizable at all sizes
- Purpose: Both `any` and `maskable` (square with safe zone)

## Maskable Icons
For maskable icons, keep important content within 80% of the center to account for different device shapes (circle, squircle, etc.).
